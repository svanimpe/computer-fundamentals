# Computer Fundamentals

In this repository you will find the learning path and materials used in the lessons of the course Computer Fundamentals (1st year bachelor Applied Informatics at Hogeschool Gent).

## Development

Install the dependencies and start the development server with the following commands:

```bash
npm install
npm run dev
```

Open [http://localhost:5173/preface](http://localhost:5173/preface) to view the site in the browser.
